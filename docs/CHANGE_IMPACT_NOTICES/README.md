# Change Impact Notices

Use this directory for any Jarvis change that may remove, degrade, replace, or materially alter an existing feature, API contract, persistence shape, workflow, or subsystem boundary.

Codex must create a notice and stop for explicit approval before implementing the risky portion.

## Template

```md
# Change Impact Notice: <Title>

## What Would Change

## Why It Is Needed

## Benefits

## Risks

## Side Effects

## Migration Path

## Rollback Path

## Exact Files Affected

## Reversibility

## Approval Question

Do you approve implementing this change?
```
